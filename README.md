# middleware-automation
This repository contains automation and monitoring scripts for **IBM MQ** and **IIB/ACE** environments.  
These scripts assist in queue management, access setup, BAR deployments, execution group management, and toolkit operations, improving efficiency and reliability in middleware administration.

---
Notes
Scripts are generic and safe, with no client-sensitive information.
Recommended for Linux/AIX/ environments with IBM MQ/IIB installed.
Always review script variables before running in production environments.
---
